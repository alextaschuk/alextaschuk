## Previous Projects

- **[Clock-Based Text Detection using Deep Learning](https://github.com/alextaschuk/Clock-Based-Text-Detection)** _Transformers_, _Token Classifier_, _OpenAI_
    - Explored the possibility of using machine learning to detect sentences in books that mention an explicit hour and minute of the day. Built two pipelines and compared the results: the first approach used a fine-tuned transformer model (spoiler alert, it wasn't very good). The second approach used a fine-tuned token classifier to tag any temporal text, then GPT-5.4 mini to filter any tagged text that wasn't clock-related (e.g., remove "yesterday" but keep "1:43 P.M.").

- **[TCP Congestion Anomaly Detection](https://github.com/alextaschuk/TCP-Congestion-Anomaly-Detection)** _C_, _TensorFlow_, _Keras_
  - Implemented TCP from scratch in C (did not use sys calls like `socket()`).
  - Trained and fine-tuned an LSTM to predict imminent congestion events (triple ACKs/timeouts) before they occur.
